/dado

A rota /dado é uma rota do tipo post onde deverá ser enviado um json seguindo o formato a seguir:
{"data": valor, "hora": valor, "sensor": valor}

/baixar_dado

A rota /baixar_dado é uma rota do tipo get que retornará o arquivo csv do banco de dados

/visualizar_dado

A rota /visualizar_dado é uma rota do tipo get que retornará os dados do banco de dados em formato json

/ultimo-dado-sensor/{sensor}

É uma rota do tipo get que retornará o último dado do sensor especificado em formato json

/pastas

É uma rota do tipo get que todas as pastas em formato json

/visualizar/{pasta}

É uma rota do tipo get que mostra um dashboard da pasta com as medições dos sensores

/nova-simulacao

É uma rota do tipo get que reseta a Máquina Virtual para poder realizar uma nova medição
